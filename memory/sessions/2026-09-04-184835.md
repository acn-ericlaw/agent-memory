## What happened

Shipped **v4.39.2 (PATCH)** — fixed the changed-config secret scan's silent abort when the
LAST changed credential-class config file is waived via `.agent/secret-scan-ignore`.

- **Field origin:** maintainer fix report (`/tmp/agent-memory-secret-scan-fix.md`, 2026-09-04)
  from `Accenture/mercury-composable` PR #318 — the first PR ever to exercise a waiver entry
  in that repo. The `memory` check died in ~7s with a hard, **outputless** `exit 1`.
- **Root cause:** the exemption filter's loop body ended in
  `[ "$keep" = "1" ] && printf '%s\n' "$f"`. For a waived trailing file the false test is
  the loop's exit status → the command substitution's status → the **assignment's** status,
  and the runner's `set -e` aborts before anything prints. A false `if` condition is exempt
  from `-e`, so the one-line fix is `if [ "$keep" = "1" ]; then printf '%s\n' "$f"; fi`.
- **Applied to all three floors** (identical loop confirmed in each):
  `.github/workflows/agent-memory.yml`, `templates/.gitlab/agent-memory-ci.yml`,
  `templates/.azuredevops/agent-memory-ci.yml` — each with a comment pinning the reason.
- **Class sweep** (per the report's audit request): the pre-commit
  `50-agent-memory-secret-guard` fragment already uses the safe `if/else` form (lines 56–57,
  matching the reporter's downstream observation); `sync-adapters.sh`'s
  `[ ... ] && DRY=1` runs with no `set -e` (deliberately Bash-3.2-safe) — safe; the
  workflows' other `[ ... ] && { ...; exit 0; }` / `&& exit 1 || true` lines are safe
  because the failing test is a non-final `&&`-list command, exempt from `-e`. No other
  instance of the class found in shipped shell.
- **Regression test:** new `tests/test_ci_secret_scan_waiver.sh` — static idiom guard on all
  three floors (any bash) + behavioral cases that extract each floor's filter loop
  **verbatim** (per the verbatim-fixture rule) and run it under `set -e` against the
  motivating fixture and three neighbors (last-file-waived, last-file-not-waived, both
  orderings of a waived+unwaived pair). Behavioral cases need bash ≥ 4 (macOS 3.2 cannot
  parse `case` inside `$(...)`; the forge runners qualify) and skip locally with a notice.
- **Verification:** mechanism reproduced locally (pre-fix: silent exit 1; post-fix: exit 0
  with the waived file filtered); the extraction harness green on all 12 case×floor
  combinations; **red-verified** — reverting the one line makes the motivating case abort
  exactly as in the field. Static guard passes locally.
- **Version ladder:** `VERSION` 4.39.1 → 4.39.2; CHANGELOG entry; UPGRADE.md ladder row +

Durable lesson: in `-e`-governed shell, never end a loop, function, or command-substitution
body with a bare test-and-act (`[ ... ] && ...`) — the false test becomes the compound's exit
status and fails the enclosing assignment; use `if ... fi`. The failure class fires
preferentially on the *first legitimate use* of a feature whose happy path CI never
exercised, and masquerades as infrastructure flakiness.
